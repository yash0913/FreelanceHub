# pages/freelancer/

This folder will house components specific to Freelancer profiles and jobs search/bidding:
- `FreelancerDashboard.jsx` - Main workspace displaying submitted proposals and active projects.
- `JobSearch.jsx` - Search/filters to explore open jobs. Includes natural language searching.
- `ProposalForm.jsx` - Form to bid on jobs and submit cover letters.
- `ProfileEdit.jsx` - Form to update skills, hourly rate, and profile bio.
- `ContractDetails.jsx` - Manage ongoing tasks and submit customer reviews.
