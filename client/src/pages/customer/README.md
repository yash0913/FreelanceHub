# pages/customer/

This folder will house components specific to Customer dashboards and activities:
- `JobPostForm.jsx` - Form to create new job listings.
- `CustomerDashboard.jsx` - View showing open postings, proposals received, and active projects.
- `ProposalDetails.jsx` - Inspect bids, compare freelancer profiles, and accept proposals.
- `ContractDetails.jsx` - Track active projects, manage payments, and submit freelancer reviews.
