# controllers/

This folder will house controllers for HTTP endpoints:
- `authController.js` - Sign in, sign up, token refresh callbacks.
- `userController.js` - Profile retrieval/update callbacks.
- `freelancerController.js` - Profile listings callbacks.
- `jobController.js` - Jobs listing, bidding, and detail views callbacks.
- `proposalController.js` - Proposal creations, status modification callbacks.
- `projectController.js` - Contract management callbacks.
- `reviewController.js` - Feedback submissions callbacks.
- `adminController.js` - Flags management and moderation callbacks.
- `nlpController.js` - Receives natural language inputs and initiates SQL generation pipelines.
